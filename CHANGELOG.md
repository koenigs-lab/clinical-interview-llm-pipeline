# Changelog

## 0.3.1 (2026-11-27)

- `install.sh` sets up Python, the environment, and the pipeline with its optional parts in one step, runs the tests, and shows `cilp --help`.
- The README names the model format each step expects. Training and prediction read Hugging Face model folders, and GGUF files serve the identifier search.
- The workflow guide shows how jobs run side by side on several GPUs.
- The tests pass with all optional parts installed.
